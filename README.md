# Plataforma Reino Online

Este repositório está preparado para publicar a Plataforma Reino no GitHub Pages.

## Estrutura esperada
Coloque na raiz do repositório os arquivos da pasta `plataforma-reino-html`, incluindo:
- index.html
- quiz.html
- historia.html
- assets/
- demais arquivos do projeto

O workflow em `.github/workflows/pages.yml` fará a publicação automática após o envio dos arquivos.
